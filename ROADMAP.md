# Roadmap

## Phase 0 — Open-source foundation

- [x] Establish the public project identity and core research framing.
- [x] Add an open-source license.
- [x] Document the proposed verification architecture and human-sovereignty principle.
- [ ] Publish the initial reference web interface and proposal schema.
- [ ] Add contribution guidelines, issue templates, and benchmark conventions.

## Phase 1 — Structured proposal model

- [ ] Define a versioned JSON/TypeScript schema for proposals, assumptions, constraints, evidence, objections, and decisions.
- [ ] Implement deterministic validation for required fields, types, internal consistency, and traceability links.
- [ ] Add examples of well-formed and intentionally malformed proposals.
- [ ] Define machine-readable evaluation events and audit records.

## Phase 2 — Semantic Firewall MVP

- [ ] Implement an OpenAI-backed analysis adapter with reproducible prompts and structured outputs.
- [ ] Detect ambiguity, contradictions, missing assumptions, and possible constraint conflicts.
- [ ] Separate deterministic findings from model-generated findings.
- [ ] Add confidence/uncertainty fields and human-review states.
- [ ] Build benchmark cases with expected findings and scoring rubrics.

## Phase 3 — Adversarial evaluation

- [ ] Run independent analyses from multiple objective perspectives.
- [ ] Generate counterarguments, failure scenarios, and second-order effects.
- [ ] Compare model agreement/disagreement and evaluate calibration.
- [ ] Add red-team benchmark suites for hidden conflicts and misleading formulations.

## Phase 4 — Auditable explanations

- [ ] Generate concise public-facing explanations linked to source assumptions and checks.
- [ ] Preserve provenance for each claim and model output.
- [ ] Add reproducible experiment manifests and result exports.
- [ ] Publish evaluation datasets and reference runs where licensing permits.

## Phase 5 — Community research

- [ ] Invite contributors in AI safety, formal methods, controlled natural language, governance research, and evaluation design.
- [ ] Add independent benchmark submissions and external model adapters.
- [ ] Publish comparative reports on verification accuracy, robustness, and failure modes.

## Non-goals

The project is not intended to automate binding legal or political decisions, replace accountable human institutions, or deploy autonomous coercive control. The open-source reference implementation is for research, simulation, verification, and transparent decision support.
